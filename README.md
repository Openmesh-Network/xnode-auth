# Xnode Auth

In domain NGINX [auth_request](https://nginx.org/en/docs/http/ngx_http_auth_request_module.html) authenticator and login dashboard.

## Supported Authentication Protocols

- Ethereum signatures
- Passkeys
- Password
- IP address

## Commands

```
nix build
nix develop
nix run
```

or

```
npm i
npm run dev
npm run build
```
